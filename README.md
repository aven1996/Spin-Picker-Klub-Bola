Spin Picker untuk mengundi Klub Bola dengan backend google app script dan penyimpanan di google sheet. Tambahan fitur :  Generate jadwal pertandingan secara otomatis dan membuat halaman klasemen

Pada tab Google Sheets `Peserta`, isi kolom `Nama Peserta` dan kolom `Image` dengan URL HTTPS langsung ke file gambar PNG, misalnya `https://cdn.example.com/foto-peserta.png`. URL harus mengarah langsung ke file gambar yang dapat diakses publik, bukan ke halaman pratinjau atau halaman berbagi. Cara ini memuat file PNG asli agar transparansi latarnya tetap terjaga. ID Google Drive lama tetap didukung sebagai fallback, tetapi thumbnail Drive mungkin tidak mempertahankan transparansi.
