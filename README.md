Spin Picker untuk mengundi Klub Bola dengan backend google app script dan penyimpanan di google sheet

Pada tab Google Sheets `Peserta`, isi kolom `Nama Peserta` dan kolom `Image` dengan ID file gambar Google Drive (bukan URL). ID terdapat pada URL berbagi gambar, misalnya `https://drive.google.com/file/d/FILE_ID/view` — salin bagian `FILE_ID` saja. Pastikan akses file diatur ke "Siapa saja yang memiliki link". Foto peserta akan ditampilkan berbentuk lingkaran di tabel klasemen setelah peserta mendapatkan klub.
