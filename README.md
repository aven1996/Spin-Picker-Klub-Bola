Spin Picker untuk mengundi Klub Bola dengan backend google app script dan penyimpanan di google sheet. Tambahan fitur :  Generate jadwal pertandingan secara otomatis dan membuat halaman klasemen

Letakkan file foto peserta di folder `emblem` di dalam proyek dan sertakan folder tersebut saat proyek dipublikasikan. Pada tab Google Sheets `Peserta`, isi kolom `Image` dengan nama file beserta ekstensinya, misalnya `budi.png`. Nama file harus sama persis dengan file di folder `emblem`. PNG transparan akan ditampilkan tanpa latar tambahan; kolom ini tidak lagi menggunakan ID atau URL Google Drive. Setelah memperbarui `Kode.gs`, perbarui deployment Google Apps Script agar mengirim nama file dengan properti `imageFile`.
